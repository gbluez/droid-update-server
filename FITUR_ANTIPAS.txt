1. MULTI-PROTOCOL DEVICE DISCOVERY & KONEKTIVITAS
--------------------------------------------------------------------------------
- Auto-Discovery Multi-Bus Cerdas:
  * ADB (Android Debug Bridge): High-Speed Direct Socket DLL (antipas_adb.dll) & Native CLI.
  * Fastboot (Bootloader): Komunikasi langsung endpoint bootloader hardware vendor.
  * MTP (Media Transfer Protocol): Penjelajahan media storage Windows Portable Devices.
  * Modem / Service Port: Port serial COM / AT command & mode META MediaTek.
  * Sideload: Saluran pembaruan paket OTA recovery.
  * Huawei HDB: Sinkronisasi jembatan debug khusus perangkat Huawei & HiSilicon Kirin.
  * Transsion & OPLUS Preloader: Deteksi port handshake BROM MediaTek & Unisoc.
- Smart Device ComboBox:
  * Menampilkan informasi serial, protokol aktif, codename perangkat, dan status lock.
  * Format: [SERIAL] [PROTOKOL:KODE_MESIN] NAMA_PRODUK (STATUS_LOCK)
  * Contoh: [QSGEMBQCFIWC9PTG] [FASTBOOT:dew] dew (LOCKED)
- Tombol Aksi Adaptif:
  * Label tombol otomatis berubah mengikuti perangkat: 
    "⚡ CONNECT FB", "CONNECT MTP", "CONNECT COM", atau "CONNECT ADB".
  * Otomatis berubah menjadi "DISCONNECT" saat sesi aktif tersambung.
- Hardware & Driver Intelligence:
  * Membaca informasi Vendor ID (VID), Product ID (PID), nama driver USB, dan status INF 
    secara real-time melalui Windows SetupAPI & CfgMgr32.
- Device Manager Smart Fallback:
  * Mampu mengenali perangkat yang driver-nya bermasalah tanpa menimpa node Fastboot valid.


2. FASTBOOT ENGINE & BOOTLOADER MASTER CONTROLLER
--------------------------------------------------------------------------------
- ⚡ Connect Fastboot (Direct Link & Sync):
  * Membuka koneksi bus langsung ke endpoint bootloader tanpa perantara daemon ADB.
- Smart Telemetry & Diagnostic (getvar all parser):
  * Security Matrix: Status Bootloader (LOCKED/UNLOCKED), status FRP (PERSISTENT/DISABLED), 
    dan Security Engine (SECURE-BOOT S-ON / ENGINEERING S-OFF).
  * Hardware Identity: Device Serial, Product Name, SKU/Variant, active slot.
  * System Firmware: Versi bootloader dan baseband modem radio.
  * Partition Topology: Menampilkan seluruh kapasitas dan tipe partisi (>70 partisi: 
    system, vendor, boot, vbmeta, super, nvdata, nvram, preloader, dll.) 
    dengan alokasi heap 64KB aman anti-crash.
- Bootloader Lock & Security Wipe:
  * Unlock Bootloader: Eksekusi "flashing unlock" & "oem unlock".
  * Lock Bootloader: Eksekusi "flashing lock" & "oem lock".
  * Erase FRP Lock: Menghapus partisi proteksi akun Google (FRP) via Fastboot.
  * Wipe Userdata & Cache: Reset pabrik total via Fastboot (fastboot -w).
  * Switch Active A/B Slot: Mengganti partisi aktif slot A/B (set active other).
- Flashing & Image Management:
  * Flash Boot Partition: Flashing kernel boot image (boot.img).
  * Flash Recovery Partition: Flashing kustom recovery (TWRP/OrangeFox).
  * Boot Temporary Image: Boot file image ke RAM sementara tanpa menimpa flash memory.
  * Dump All Variables: Dump seluruh variabel bootloader (getvar all).
  * OEM Device Info: Membaca rincian perangkat OEM vendor (oem device-info).
- Advanced Power & Reboot Handlers:
  * Reboot Normal (System).
  * Reboot Bootloader / Fastboot.
  * Reboot Recovery Mode.
  * Reboot FastbootD (User-Space Fastboot untuk Android 10+).
  * Reboot Emergency Download Mode (Qualcomm EDL 9008).
